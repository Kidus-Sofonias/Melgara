# Ore 3D Models

Place .glb ore model files here:
- copper.glb
- manganese.glb
- chrome.glb
- iron.glb
- nonmetallic.glb

Free sources for ore/rock models:
- https://poly.pizza/search/rock
- https://sketchfab.com/search?type=models&q=ore+mineral&downloadable=true
- https://www.meshy.ai/tags/mineral

If no model is found, the app falls back to procedural + photo rendering.
